FOR MY AYESHA — SCROLLING MEMORY WEBSITE

This is a mobile-friendly, one-page romantic website. Open index.html to preview it locally. Keep the assets folder next to index.html; do not move or rename the media files.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository (for example: for-my-ayesha).
2. Extract this ZIP on your phone/computer.
3. Upload index.html and the complete assets folder to the repository's root (not the ZIP file itself).
4. In the repository, open Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish, then open the URL shown in Settings -> Pages and share that link with Ayesha.

Videos are included locally. They will load from the website when the browser supports MP4 playback. This site does not collect or send any personal data.
